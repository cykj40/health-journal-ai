Data Flow
Journal entry saved ↓ Dexcom CGM fetch (±2hr window around entry.createdAt) ↓ analyzeEntry(content, cgmContext) ← richer AI because it sees actual glucose ↓ health_metrics stored (40+ fields) device_glucose_avg/min/max/trend stored on entry_analysis ↓ DexcomEventConfirm card appears ← HITL: one card per event type User taps "Log to Dexcom" per event ↓ POST /api/dexcom-log → log_exercise / log_carbs on Dexcom MCP ↓ T1Copilot reads logged events ← via Dexcom MCP shared timeline Correlates with CGM + Peloton data
